# Contributing to Kashida Branch Locator

Thank you for helping improve Kashida Branch Locator.

## Reporting bugs
- Search existing issues first to avoid duplicates.
- Use the Bug Report template.
- Include steps to reproduce, plugin/WordPress/PHP versions, and relevant logs.
- Remove credentials, personal data, and other sensitive information before posting.

## Suggesting features
- Use the Feature Request template.
- Describe the problem, proposed solution, and expected benefit.

## Code contributions
1. Fork the repository and create a focused branch.
2. Keep changes scoped and avoid unrelated refactoring.
3. Run the PHP syntax workflow and test affected plugin behavior in a WordPress test site.
4. Open a pull request with a clear description and test results.

## Guidelines
- Prioritize security, performance, accessibility, compatibility, and translation support.
- Do not commit credentials, private data, or production database contents.
- Preserve the plugin's GPL-2.0-or-later licensing.
