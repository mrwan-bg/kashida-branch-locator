== Display Builder ==

The Groups screen includes a Display Builder. Select the layout and the information/options to show, then copy the generated shortcode.

Supported display fields include branch name, city, address, phone, and group. Search, pagination, call and directions buttons, results per page, map height, and map zoom can also be configured.


Bulk selection:
- In Groups, select multiple groups to generate one combined shortcode or delete them together.
- In Branches, select multiple branches to generate one combined shortcode or delete them together.
- Combined group shortcode uses `groups="slug1,slug2"`.
- Combined branch shortcode uses `branches="slug1,slug2"`.


Display Builder preview:
- The Display Builder includes a live visual preview of the selected layout and options.
- The preview is illustrative; the generated shortcode is the final configuration used on the frontend.

Map notes:
- Map and Map + Table skip branches that do not have valid non-zero coordinates.
- A clear message is shown when no valid coordinates are available.

Behavior:
- Visitors can search immediately without reloading the page.
- Sortable table headings show an arrow and can be clicked to change the sort order.
- Search, filters, sorting, and pagination work together.
- Map and map-table layouts update visible markers when search or filters change.
- Clicking a map marker selects the matching branch in the table when available.
- Small-screen tables switch to a compact card-style presentation.


Cards layout customization (v2.5.24)
-----------------------------------
Use these optional attributes with [kashida_branch_locator]:

- columns="3" — number of card columns (1–6; responsive on tablet and mobile).
- group_cards="true" — group Cards layout under a heading for each branch group.
- call_color="#12b76a" — background color for Call buttons.
- directions_color="#1769e8" — background color for Directions buttons.
- city_filter="true" — show the city dropdown filter (already supported).

Example:
[kashida_branch_locator layout="cards" columns="3" group_cards="true" city_filter="true" call_color="#159947" directions_color="#2459d3"]
